- Projeto ChatGPT não pode ser confundido com executor nem com Projeto de Governança.
- Memória exclusiva deve ser tratada como fronteira contextual, não como armazenamento local.
- Work deve ser marcado como indisponível dentro de Projeto com memória exclusiva.
- Arquivos locais do Notebook devem ser working copy, não fonte única de verdade.
- Limite do Plus deve ser tratado como teto de plataforma, não como meta de preenchimento.
- Transferência para Work/Codex deve usar contexto explícito e verificável.
