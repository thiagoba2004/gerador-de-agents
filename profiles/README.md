# Profiles

Perfis dos projetos gerados ou auditados pelo Gerador de Agents.

Cada perfil deve registrar, quando aplicável:

- `project_id`;
- nome e finalidade do projeto;
- repositório ou fonte de persistência;
- versão do kernel utilizada;
- módulos ativados;
- arquivos canônicos;
- ferramentas e integrações relevantes;
- riscos e restrições;
- estado de migração/implantação;
- referência ao `STRATEGY_LOG.jsonl` local.

O perfil não substitui os arquivos canônicos do projeto de origem.
